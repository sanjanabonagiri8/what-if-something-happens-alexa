
# Alexa Emergency Assistant

## Overview

**What If Something Happens? – Alexa Emergency Assistant** is an Alexa skill prototype designed to help everyone prepare for unexpected emergencies through simple voice interaction.

The skill provides general emergency preparedness guidance. The project aims to make preparedness information easier to understand for everyone, with accessibility and inclusive design considered throughout development.

## Features

- Welcomes users and explains how to interact with the skill.
- Provides basic emergency preparedness guidance.
- Reminds users to prepare essential supplies, including water, a first aid kit, a flashlight, and necessary medicines.
- Encourages users to keep emergency contacts available.
- Recommends learning local emergency exits and creating a household emergency plan.
- Reminds users to consider how they will receive emergency alerts and obtain assistance based on their individual needs.

## Amazon Technologies Used

- **Alexa Skills Kit (ASK):** Handles voice interactions and custom intents.
- **Alexa-hosted Node.js:** Runs the skill's code and processes Alexa requests.
- **Alexa Developer Console:** Used to configure, build, and test the skill.

## How to Test

1. Open the [Alexa Developer Console](https://developer.amazon.com/alexa/console/ask).
2. Select the **Emergency Assistant** skill.
3. Open the **Test** tab.
4. Set the skill stage to **Development**.
5. Enter these commands in the Alexa simulator:

   - `open emergency assistant`
   - `give me emergency guidance`

The skill should respond with a welcome message or general emergency preparedness guidance.

## Safety and Limitations

This is an emergency preparedness prototype, not an emergency response or dispatch service.

The skill does not call 911, contact emergency contacts, automatically send alerts, or dispatch emergency services. Its guidance is general and may not cover every emergency situation.

**If someone is in immediate danger in the United States, call 911 directly. Do not wait for the skill to respond.**
