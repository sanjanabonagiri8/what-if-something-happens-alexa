# What If Something Happens?
## Alexa Emergency Assistant 

An accessibility-focused emergency preparedness prototype designed to help people prepare for unexpected emergencies through a simple, user-friendly interface.

Live Demo

[Try the live demo](https://what-if-emergency-assistant.lovable.app/)

## Features

- Accessibility-focused interface
- Voice input support
- Emergency preparation assistance
- Keyboard navigation
- Mobile-friendly design

Note: This is a prototype and is not a substitute for emergency services.
