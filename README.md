# What If Something Happens? – Alexa Emergency Assistant

## Overview

What If Something Happens? – Alexa Emergency Assistant is an emergency preparedness project designed for everyone. It combines a web prototype built with Lovable AI and an Alexa skill prototype that provides simple spoken guidance to help people prepare for unexpected situations.

Accessibility and inclusive design are important considerations throughout the project, while the overall goal is to make emergency preparedness easier to understand and approach for everyone.

## The Problem

Unexpected emergencies can leave people feeling confused, frightened, or unsure about what to do. People may not know what supplies to prepare, which steps to take, or how to plan ahead.

Everyone deserves access to clear and understandable emergency preparedness information. People have different abilities and needs, so preparedness resources should aim to be simple, inclusive, and easy to access.

## My Solution

I built a web prototype and an Alexa skill prototype to explore how technology can make emergency preparedness guidance easier to access.

The Alexa skill welcomes users and provides basic preparedness reminders, including how to:
- Keep a first aid kit, drinking water, a flashlight, and essential medicines ready.
- Keep emergency contacts available.
- Learn local emergency exits.
- Create an emergency plan with household members.
- Consider how to receive alerts and obtain assistance based on individual needs.

The project is intended for everyone, including families, students, older adults, caregivers, people with disabilities, and anyone who wants to be better prepared.

## Amazon Technology

- **Alexa Skills Kit:** Enables voice interaction and handles the custom emergency guidance intent.
- **Alexa-hosted Node.js:** Runs the skill's request-handling code in the Alexa-hosted environment.
- **Alexa Developer Console:** Used to configure, build, and test the skill.

## How to Test

1. Open the Alexa Developer Console.
2. Select your skill and open the **Test** tab.
3. Set the skill stage to **Development**.
4. Try these commands in the Alexa simulator:

   - `open emergency assistant`
   - `give me emergency guidance`

The skill should respond with a welcome message and basic emergency preparedness guidance.

## Safety and Limitations

This project is currently an emergency preparedness prototype. The Alexa skill provides general preparedness guidance; it does not call 911, contact emergency contacts, automatically send alerts, or dispatch emergency services.

It is not a replacement for professional emergency assistance. If someone is in immediate danger in the United States, call 911 directly.
